# Detecção e Rastreamento de Mãos com OpenCV e MediaPipe

![Status-Concluído](https://img.shields.io/badge/Status-Concluído-brightgreen?style=for-the-badge&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

Projeto desenvolvido em Python utilizando as bibliotecas OpenCV e MediaPipe para detectar e rastrear mãos em tempo real pela webcam, identificando os pontos e as conexões dos dedos.

---
## 📚 Aprendizados
- Utilização das bibliotecas OpenCV e MediaPipe para visão computacional.
- Captura e processamento de imagens pela webcam.
- Detecção e rastreamento de mãos em tempo real.
- Identificação dos pontos de referência das mãos (landmarks).
- Mudança de cores nos pontos de referência.
- Conversão de imagens do formato BGR para RGB.
- Aplicação de funções, estruturas de repetição e condicionais.
- Configuração e execução do código no Visual Studio Code.

## ⚙️ Funcionalidades
- Captura de vídeo em tempo real pela webcam.
- Detecção automática de até duas mãos.
- Identificação dos pontos de referência dos dedos e das mãos.
- Exibição das conexões entre os pontos identificados.
- Espelhamento da imagem para facilitar a visualização.
- Encerramento do programa ao pressionar a tecla Espaço.

## 🛠️ Stack
- Python
- OpenCV (cv2)
- MediaPipe
- Visual Studio Code

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/BiaHashi/Detectando_Gestos
```

2. Abra o arquivo ".py" e execute-os pelo VS Code para ver o resultado.
